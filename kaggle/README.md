# Kaggle files

`tasks/` holds Kaggle Benchmarks task files, generated by `scripts/make_tasks.py`. The public benchmark is `fairscreen-direct.py`, `fairscreen-fairness-instruction.py` and `fairscreen-structured.py`. Each scores 48 families: eight paired decisions across qualification, identity and presentation. `fairscreen-evidence-sufficiency.py` is a secondary task. `fairscreen-dev-smoke.py` is a development check, not part of the benchmark.

`run_panel.sh` and `run_sufficiency.sh` push and run the tasks, stopping when the Model Proxy quota is low.
